How to use yScannor effectively

Use it quickly on mobile

Open the page from your phone, paste a website link, and start cloning in a few taps. This is useful for collecting references while browsing on the go.

  • Quick URL input and paste button
  • Depth control for fast or deep clones
  • Download ready ZIP after completion

Best for desktop research workflows

On desktop you get clear visibility across logs, stats, and output progress. Teams use this for migration checks, audit snapshots, and offline QA review.

  • Live file-level activity logs
  • Error count and total file tracking
  • Structured output for easy inspection
